Supplier Entity Resolution — Data Analyst POC

Overview

This project is a proof-of-concept (POC) for a procurement digitalization initiative.

The goal is to resolve a messy supplier database by matching entries to real-world companies, identifying data quality issues, and proposing a curation strategy.

Challenge Structure

1.Entity Resolution — match supplier entries to real companies

2.Data QC — identify inconsistencies in the dataset

3.Summary — document findings and recommendations


Tools Used

Excel — entity matching and data review
Google / LinkedIn / Company websites — manual entity verification

Methodology

Reviewed each supplier entry and its 5 candidate matches

Selected the best match based on name, country, and industry

For unmatched entries, performed manual research online

Flagged data inconsistencies and documented observations
